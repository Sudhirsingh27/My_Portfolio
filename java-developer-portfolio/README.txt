# Java Developer Portfolio

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best development experience, open the folder in VS Code and use Live Server.

## Files
- index.html — portfolio structure/content
- style.css — responsive design
- script.js — mobile menu, active navigation and back-to-top button

## Before publishing
Replace:
- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- Project demo links (`href="#"`)

You can also add your resume PDF and a Resume button in `index.html`.
